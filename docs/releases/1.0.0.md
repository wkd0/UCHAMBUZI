# UCHAMBUZI 1.0.0

**Publication : 12 novembre 2026 · Kali Linux amd64.**

## Périmètre livré

- Terminal Textual et Rich : Assist, OSINT Team, saisie multiligne, historique
  avec brouillons, complétion slash, Markdown en streaming local et huit thèmes.
- Catalogue interactif de 36 entrées, fiches explicatives et préparation
  individuelle des six copies embarquées : gau, Maigret, Holehe, PhoneInfoga,
  Social Analyzer et Blackbird. Installation hors ligne depuis les artefacts vérifiés.
- WhatsMyName natif, raccourcis d’indices et six playbooks guidés.
- Approbations explicites ; shell libre `!` et `/terminal` avec capture journalisée.
- Dossiers `/investigation`, journal UTC chaîné SHA-256, rapports Markdown et
  conversations sauvegardées ou reprises explicitement après vérification.
- Résultats numérotés et recherchables, copie et conseils contextuels `/tips`.
- Ollama local, RedSage proposé par défaut, accès distants facultatifs Responses
  et Claude Code, profils nommés et approbation avant transmission distante.
- Paquet Debian `uchambuzi_1.0.0-1_amd64.deb`, application 1.0.0. Les bundles
  tiers exigent Python 3.13 et `python3.13-venv` ; le Python principal peut être 3.14.

## Limites

Red, Blue et Purple restent indisponibles. Les services OSINT peuvent refuser
ou limiter les requêtes ; les résultats doivent être recoupés. Les recherches
réseau nécessitent Internet et l’accord de l’enquêteur.

La recherche de modèles distants est validée avec des réponses simulées ; la
compatibilité avec un fournisseur réel, notamment MrBoi, reste à confirmer.
Les clés saisies peuvent être enregistrées dans un fichier local `0600` non
chiffré. La sélection d’un modèle ne garantit pas sa disponibilité ni sa qualité.
RedSage reste en calibration et n’est pas inclus dans le paquet.

Le journal SHA-256 n’est ni signé ni ancré à l’extérieur. Les conversations sont
stockées sans chiffrement ; les détecteurs de secrets et d’injections sont partiels.
La reprise ne restaure aucune autorisation. Le shell garde les droits de
l’utilisateur et peut écrire hors du dossier ; l’accord de `/terminal` couvre
la session entière.

## Installation

Télécharger le paquet et `SHA256SUMS` depuis la
[release officielle v1.0.0](https://github.com/wkd0/uchambuzi/releases/tag/v1.0.0).

```sh
sha256sum --ignore-missing -c SHA256SUMS
sudo apt install ./uchambuzi_1.0.0-1_amd64.deb
uchambuzi --version
uchambuzi doctor
uchambuzi
```

Dans le terminal : `/settings`, `/tips`, puis `/team 1`,
`/investigation create exercice-v1`, `/tools` et `/investigation log`.
Voir les [commandes](../commandes.md), les [licences](../../THIRD_PARTY.md) et
les [prérequis](../installation.md).
