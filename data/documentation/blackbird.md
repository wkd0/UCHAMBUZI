# blackbird — référence locale

Description : Recherche de comptes par pseudonyme sur des sites publics.

Options passives / bornage : Aucun drapeau de recherche passive ; --help affiche uniquement une aide locale.

Options actives : --username PSEUDO déclenche des requêtes vers les sites : actif, accord requis.

Syntaxe et exemple typique : `blackbird --username example_user`

Toute opération réseau nécessite approbation [o/N]. Présence et version installées à vérifier ; cette fiche ne prouve pas leur disponibilité.
