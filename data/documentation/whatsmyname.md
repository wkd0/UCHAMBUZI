# whatsmyname — référence locale

Description : Jeu de règles JSON de reconnaissance de comptes ; aucun CLI amont universel.

Options passives / bornage : Lecture locale de wmn-data.json uniquement : passive. Aucun drapeau CLI de recherche officiel.

Options actives : La vérification des profils par un consommateur du dataset est active. Ne pas inventer whatsmyname --username ou -u.

Syntaxe et exemple typique : `API Python interne UCHAMBUZI : osint_wmn.check_username("example_user", limit=50), uniquement après accord. Aucune commande shell whatsmyname garantie.`
