# holehe — référence locale

Description : Vérifie les indices de présence d’un courriel via les mécanismes des sites.

Options passives / bornage : Aucun mode passif de recherche. --only-used filtre les résultats, sans réduire le caractère actif.

Options actives : EMAIL est un argument positionnel ; requêtes vers les services de comptes/récupération : actif, accord requis.

Syntaxe et exemple typique : `holehe investigator@example.org --only-used`

Toute opération réseau nécessite approbation [o/N]. Présence et version installées à vérifier ; cette fiche ne prouve pas leur disponibilité.
